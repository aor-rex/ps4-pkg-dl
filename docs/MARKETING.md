# MARKETING.md — ps4-pkg-dl landing page

## Target Market & Avatar

- **Niche:** Linux users who keep their own PS4 PKG sets and catalog files.
  Not generic "gamers", not enterprises.
- **Avatar:** Runs Linux daily. Has a folder of PKGs or a `games.json` link.
  Has tried scattered scripts and forum threads. Wants one app that shows
  covers, tracks what is downloaded, and resumes interrupted large transfers.
  Comfortable pasting a terminal command; does not want a sysadmin project.
- **USP (passes the swap test):** The only Linux desktop app that turns your
  own `games.json` catalogs into a browsable, artwork-enriched library with
  pause/resume downloads.
- **Primary goal:** visitor pastes the installer one-liner.

## Before / During / After Grid

| Stage | Page job |
|---|---|
| Hero | Make the outcome concrete; installer command in reach |
| Features | Answer "what does it do for me" in the visitor's words |
| Screenshots | Proof the app exists and looks real |
| Install | The one action: copy/paste a single command |
| FAQ | Kill the last objections before installing |
| Changelog, stats band, eyebrows, marquee | Serve none of the above — flagged for Phase 10 cut list |
